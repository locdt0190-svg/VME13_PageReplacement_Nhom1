# VME13_PageReplacement_Nhom1
Đồ án Hệ điều hành: Mô phỏng thuật toán thay thế trang (FIFO, LRU, OPT, Second-Chance) bằng Python (Tkinter).

## 1. Cấu trúc thư mục
- `source/`: Chứa mã nguồn giao diện (`main.py`) và thuật toán (`algorithms.py`).
- `input/`: Chứa các file dữ liệu đầu vào `.csv`.
- `output/`: Chứa các file kết quả xuất ra `.csv`.
- `report/`: Chứa báo cáo đồ án.

## 2. Định dạng file CSV đầu vào
- Dòng 1: Số lượng khung trang (số nguyên dương, ví dụ: `3`).
- Dòng 2: Chuỗi số hiệu trang cách nhau bởi dấu phẩy (ví dụ: `7,0,1,2,0,3`).

## 3. Hướng dẫn cài đặt và chạy chương trình
1. Cài đặt Python 3.x trên Windows.
2. Mở thư mục dự án bằng VS Code.
3. Mở file `source/main.py` và bấm nút Run (hoặc chạy lệnh: `python source/main.py`).
